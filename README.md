# Orbital Watch – Space Debris Alert

Dieses Projekt löst die Aufgabenstellung "Orbital Watch – Space Debris Alert" mit Python.

## Warum Python?

Python wurde gewählt, weil es für CSV-Verarbeitung, mathematische Berechnungen und schnelle Prototypen sehr gut geeignet ist. Außerdem war Python für mich eine unbekannte Programmiersprache, wodurch die Aufgabenstellung erfüllt wird.

## Funktionen

- Umwandlung von GPS-Koordinaten im Grad-Minuten-Sekunden-Format in Dezimalgrad
- Umwandlung von geodätischen Koordinaten in ECEF-Koordinaten
- Erkennung von Kollisionsrisiken zwischen Satelliten und Weltraumschrott
- Kommandozeilenmodus
- Eigene grafische Oberfläche mit Tkinter
